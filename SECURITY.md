# Política de seguridad

Este repositorio es una demo sin datos reales ni infraestructura de producción.

Si encontrás una vulnerabilidad o un dato sensible expuesto, no lo publiques: avisá de forma privada a la persona responsable del repositorio mediante la función "Report a vulnerability" de GitHub (pestaña Security) o por mensaje directo.

Nunca se deben subir a este repositorio claves de API, tokens, contraseñas, archivos `.env` ni datos personales de clientes.
